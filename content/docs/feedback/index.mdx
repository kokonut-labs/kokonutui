title: Feedback Components
description: "Free React feedback components: a promise toast, an inline alert, a save status pill, an empty state and a helpful rating, built with Tailwind CSS and Motion."
---

The parts of an app that tell people what just happened: a toast that follows a task from working to done, an alert that re-runs what failed, a pill that says whether your work is saved, an empty state that turns into your first item, and a rating that asks if a page helped. Each one is a React component built with Tailwind CSS and Motion.
