The tab list is rendered twice: the real tabs underneath, and an inverted copy on top clipped to the active tab with `clip-path: inset()`. Moving the clip moves the pill, and because it cuts through the labels, each letter switches color as the edge passes over it. Clicks slide the pill; arrow keys move it instantly.
