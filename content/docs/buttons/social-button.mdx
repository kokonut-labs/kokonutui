## Usage

```tsx
import SocialButton from "@/components/kokonutui/social-button";

<SocialButton
  placement="popover"
  shareData={{
    title: "Release notes",
    text: "What shipped this week",
    url: "https://example.com/changelog",
  }}
/>
```

On touch devices with `navigator.share`, the trigger opens the system share sheet. Elsewhere, or if the sheet fails, it opens the share row or menu.

| Prop | Type | Default | Description |
|---|---|---|---|
| `shareData` | `{ title?: string; text?: string; url?: string }` | — | What to share. `url` defaults to the current page. |
| `placement` | `"inline" \| "popover"` | `"inline"` | `inline` swaps the trigger for a row of icons; `popover` opens a menu anchored to the trigger. |
| `items` | `ShareItem[]` | X, LinkedIn, email, copy link | Share targets. `href` can be a string or `(data) => string`; `action: "copy"` copies the URL. |
| `onShare` | `(index: number, item: ShareItem) => void` | — | Called when an item is chosen. |
| `nativeShare` | `boolean` | `true` | Use the system share sheet on touch devices. |
| `label` | `string` | `"Share"` | Trigger label. |
| `icon` | `ComponentType<{ className?: string }>` | `Link` | Trigger icon. |
