## Usage

Pick a tool from **Tools**, or type `/` in an empty box and press its number, and the Tools pill turns into that tool, tinted with its `color`. Its x, picking it again, or Backspace in an empty box takes it off. A tool with a `limit` shows the runs left as dots and locks at zero. With no `onSearch` the component plays a pretend run. Wire it to your own backend by calling `onSource` as each source comes in and resolving when the answer is ready. Stop, or Esc, aborts `signal`.

```tsx
<AI_Input_Search
  onSearch={async (query, { tool, model, files, signal, onSource }) => {
    if (!tool?.readsSources) {
      return ask(query, { tool: tool?.id, model, files, signal });
    }
    for await (const source of mySearch(query, { deep: tool.id === "investigate", signal })) {
      onSource({ domain: source.host, title: source.title });
    }
  }}
/>
```

Bring your own tools with any Lucide icon:

```tsx
import { Map } from "lucide-react";

<AI_Input_Search
  defaultTool={null}
  tools={[
    { id: "places", label: "Find places", icon: Map, color: "#14b8a6", hint: "Maps, hours and reviews", activity: "Looking up places", readsSources: true },
  ]}
/>
```

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `string` | `"Ask anything, or type / for tools"` | Placeholder with no tool picked. Each tool can set its own. |
| `tools` | `SearchTool[]` | Browse sources, Investigate, Draft a visual, Run some code, Reason it through | Entries in the Tools menu: `id`, `label`, `icon`, `activity`, and optional `hint`, `color`, `placeholder`, `readsSources`, `limit`. |
| `defaultTool` | `string \| null` | `"browse"` | Tool picked at first. |
| `models` | `string[]` | `["Opus 5.5", "Sonnet 5.5", "Haiku 5.5"]` | Entries in the model menu. |
| `defaultModel` | `string` | `"Sonnet 5.5"` | Model picked at first. |
| `onSearch` | `(query, { tool, model, files, signal, onSource }) => Promise<void> \| void` | — | Runs the request. Omit it for the demo. |
| `className` | `string` | — | Extra classes for the wrapper. |
