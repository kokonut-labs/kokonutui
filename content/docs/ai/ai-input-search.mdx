## Usage

With no `onSearch` the component plays a pretend search. Wire it to your own search by calling `onSource` as each source comes in and resolving when the answer is ready. Stop, or Esc, aborts `signal`.

```tsx
<AI_Input_Search
  onSearch={async (query, { mode, signal, onSource }) => {
    for await (const source of mySearch(query, { deep: mode === "research", signal })) {
      onSource({ domain: source.host, title: source.title });
    }
  }}
/>
```

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `string` | `"Ask anything"` | Placeholder in Quick mode. |
| `researchPlaceholder` | `string` | `"Research a topic in depth"` | Placeholder in Research mode. |
| `defaultMode` | `"quick" \| "research"` | `"quick"` | Mode selected at first. |
| `onSearch` | `(query, { mode, signal, onSource }) => Promise<void> \| void` | — | Runs the search. Omit it for the demo. |
| `className` | `string` | — | Extra classes for the wrapper. |
