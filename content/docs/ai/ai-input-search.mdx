## Usage

Type an operator and a space, for example `site:github.com `, and it becomes a chip. Backspace in an empty field opens the last chip back up as text. `onSubmit` gets the query with the operators taken out.

```tsx
<AI_Input_Search
  scopes={["Web", "News", "Papers", "Code"]}
  onSubmit={(query, { filters, scope, deep }) => search(query, filters, scope, deep)}
/>
```

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `string` | `"Search anything"` | Placeholder text. |
| `scopes` | `string[]` | Web, News, Papers, Code | Where to search. |
| `defaultScope` | `string` | first scope | Scope selected at first. |
| `defaultDeep` | `boolean` | `false` | Start with Deep research on. |
| `onSubmit` | `(query, { filters, scope, deep }) => void` | — | `filters` is `{ kind: "site" \| "after" \| "before" \| "type"; value: string }[]`. |
| `className` | `string` | — | Extra classes for the wrapper. |
