description: "Free React components for AI chat and agents: prompt inputs, voice, tool calls and approvals, in-chat checkout and order tracking, citations and diff review."
---

Components for the parts of an AI product people actually touch: the prompt box and voice input, the model and effort pickers, tool calls and approvals while an agent works, the cards it shows in the chat (a checkout, a schedule, an order's status, a handoff to a person), sources and citations, and the states in between while a reply streams in. Each one is a React component built with Tailwind CSS and Motion, installed with the shadcn CLI.
