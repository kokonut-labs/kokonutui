Controls for home apps, each one a single obvious gesture: swipe a light up to dim it, turn a dial that warms from blue to orange, watch the sky behind your energy use change color, pull a shade over a glowing window, and tap to open the front door. Each one is a React component built with Tailwind CSS and Motion.
