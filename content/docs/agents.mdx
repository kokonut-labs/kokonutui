Kokonut UI is a shadcn/ui registry, so any agent that can run the shadcn CLI can install its components. Ask for a component by name, or describe what you need, and the agent finds it, installs it with its dependencies, and edits it in your codebase like any other file.

## Add the registry

Agents install from the `@kokonutui` namespace, so add it to your `components.json` once. If you don't have one yet, run `shadcn init` first, as shown in [Installation](/docs).

```json title="components.json"
{
  "registries": {
    "@kokonutui": "https://kokonutui.com/r/{name}.json"
  }
}
```

## Add a rules file

A short rules file tells your agent to check Kokonut UI before building a component from scratch, and to install rather than paste code. Save it in your project under the file name shown for your editor.
